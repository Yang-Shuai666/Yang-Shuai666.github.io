# 大大帅的个人网站

这是大大帅（YS）的个人简历与技术记录网站，使用 GitHub Pages 和 Jekyll 构建。

## 关于我

我对人工智能和技术实践保持长期兴趣，喜欢探索新工具、新方法，并把想法一步步做成可以使用的作品。

这个网站用于展示我的个人介绍、关注方向和联系方式，也记录学习过程中的思考与实践。

## 网站内容

- 首页：个人简历与当前关注方向
- 关于我：更完整的个人介绍
- 文章：AI、工程实践、建站和持续学习记录

## 本地预览

安装 Jekyll 后，在项目目录运行：

```bash
bundle exec jekyll serve
```

然后访问 `http://127.0.0.1:4000/`。
